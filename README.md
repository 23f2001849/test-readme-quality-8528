# Task Manager

## Overview
The Task Manager is a simple and efficient web application designed to help you keep track of your tasks. The purpose of this project is to provide a fast and easy way to manage your tasks in a user-friendly environment. You can add and delete tasks, providing you with a dynamic list of tasks to complete. The Task Manager uses Bootstrap 5 for a clean and responsive design that ensures an optimal user experience on all devices.

This application is particularly useful for anyone needing a simple tool to help manage their daily tasks. By leveraging modern web technologies, the Task Manager provides an accessible and easy-to-use tool for task management.

## Features
- Add tasks: Input a task into the text field and click the 'Add Task' button to add a task.
- Delete tasks: Click on the 'Delete' button next to a task to remove it from the list.
- Responsive design: The application is responsive and works well on all device sizes.

## Setup Instructions
To run the application, follow these steps:
1. Ensure you have a modern web browser installed (such as Google Chrome, Mozilla Firefox, or Safari).
2. Download the `index.html` file.
3. Open the `index.html` file in your web browser.
4. The application is now running and ready for use!

## Usage Guide
Using the Task Manager application is straightforward:
- To add a task, type your task into the text field and click the 'Add Task' button. Your task will appear in the list below.
- To delete a task, simply click the 'Delete' button next to the task you wish to remove.

## Technical Details
The Task Manager is a frontend-only web application built using HTML, CSS, JavaScript, and Bootstrap 5. It does not require any backend server or database as it stores the data temporarily on the client side. It utilizes the Bootstrap 5 framework for its responsive design and styling.

## Code Explanation
The JavaScript code is responsible for the dynamic functionality of the application. It maintains an array of tasks, and provides functions to add and delete tasks. On addition or deletion of tasks, it re-renders the task list onto the HTML document.
